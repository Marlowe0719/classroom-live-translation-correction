# 课堂实时翻译矫正

实时翻译首页：**[http://127.0.0.1:8766](http://127.0.0.1:8766)**。双击 `启动实时翻译.cmd` 可重新启动。

同音频对比保留在 **[http://127.0.0.1:8766/compare](http://127.0.0.1:8766/compare)**；API管理可直接打开 **[http://127.0.0.1:8766/compare#profiles](http://127.0.0.1:8766/compare#profiles)**。既有密钥和历史记录沿用。

本项目的 Qwen / DeepSeek 功能可以独立运行。原电脑的 **[http://127.0.0.1:8765](http://127.0.0.1:8765)** 和 `classroom-translator/` 是可选的旧版工具，不包含在此仓库中。

## 首次安装与启动

需要 Node.js 24 或更新版本。在项目目录安装依赖并启动：

```sh
npm install
npm start
```

也可以用 `pnpm install --frozen-lockfile` 安装仓库锁定的依赖，然后执行 `node server.mjs`。Windows 安装好依赖后，可双击 `启动实时翻译.cmd`；启动器会等待服务就绪再打开页面，启动失败时显示提示和日志。

Windows 启动器会检查配置接口与音频采集模块，并确认同一后台进程连续两次就绪；重复双击会依次检查，复用已有服务。每次启动的 `.startup-logs/*.launcher.log` 记录新建或复用的进程 ID、检查结果和失败原因；该目录不上传到 GitHub。启动检查不能保证后台进程此后永不退出。如果页面仍在但开始时报音频模块连接中断，请再次双击启动器，回到原页重试，已有字幕无需清除或刷新。

打开 **[http://127.0.0.1:8766](http://127.0.0.1:8766)**，进入“API 配置”填写自己的服务地址、模型和 API Key。仓库不含任何密钥、课堂录音、字幕草稿或个人历史记录。离线测试运行 `npm test`，不会调用云端模型。

腾讯兼容入口需要原电脑的 `~/.config/classroom-translator/tencent-credentials.json`；旧版“历史测试示例”需要相邻目录中的 `classroom-translator/test-result.json`。这些可选文件缺失时，不影响 Qwen / DeepSeek 的使用。不要将凭证文件上传到 GitHub。

## 使用实时翻译

1. 首页只选择一项语音识别 API 和一项中文翻译 API。当前以实时识别速度优先，默认 Qwen Audio 3 持续流式热词识别（`qwen-asr-streaming`）与 Qwen Flash 翻译（`qwen-flash-translate`）。
2. 在“课堂设置”选择金融课程、补充术语和时长上限；默认45分钟，最长可选120分钟。
3. 选择麦克风或电脑声音，点击“开始实时翻译”。电脑声音需在浏览器共享窗口选择音频。
4. 英文原文与中文译文在同一个字幕区按句连续显示；可调整字号、仅看中文或手动导出TXT。“导出 TXT”和“结束并导出”均导出上下文模块整合后的长段落，语言跟随上下文侧栏的英中双语、仅中文或仅英文选择。自动导出保存到本机 `~/Downloads/课堂字幕/`，页脚显示保存结果；达到时长上限或异常导致自动结束时也会导出。
5. “暂停”只停止采集并收尾已有语音，手动暂停不自动导出。暂停后可点击“继续翻译”，也可直接点击“结束并导出”；已有字幕保留。暂停时可更换已配置的语音/翻译API，配置与对比入口另开标签页，修改后可在课堂设置中刷新配置。
6. 点击字幕工具栏的“全屏字幕”放大课堂区域；“退出全屏”或 Esc 返回。全屏保留开始/继续、暂停、结束并导出、语言和字号控制。
7. “上下文”侧栏将同一课堂记录中已经定稿的英文、已有中文按顺序连成长段落，随字幕更新，可切换语言、复制或收起。向上阅读时保留侧栏位置。基础段落整理在本机完成，不调用 AI。
8. 侧栏“AI 校正”默认关闭。选择独立校正模型并主动开启后，结合前后段英文、原译文和金融词库修订当前段中文；可展开原译文对照，关闭后显示原译文。仅修订侧栏，不修改实时字幕、英文识别文本或原字幕草稿。
9. 暂停或结束后，点击工具栏“清除本页”，清空全部字幕、上下文、AI 校正缓存和计时，下一节课从空白页开始。API、课程设置和已导出的文件保留。清除会同步保存空草稿，刷新后不会恢复旧课；本机保存失败时保留页面文本。正在采集时请先暂停或结束，再清除。

### 上下文 AI 校正

默认校正模型优先选已配置的 DeepSeek，与当前 Qwen 识别和快译分开，也可选择已配置的 Qwen Plus、Qwen Flash 或通用 Chat 模型。开启后额外使用所选 API；专用 Qwen MT 翻译模型不用于上下文改写。

校正等待段落翻译完成并稳定后才执行，独立后台一次一段，请求启动间隔至少15秒。收起侧栏、关闭校正或离开页面会取消进行中的校正。请求超时或失败时保留原译文，不阻塞实时识别或实时翻译；不进行无限重试。历史段落逐步处理，原字幕或模型设置变化时丢弃过期结果。

模型提示使用金融课程词库，要求保留数字、单位、公式、否定、可能性和条件，避免凭空补写。上下文可以帮助修订误译，原录音中缺失的信息仍需人工核对。复制侧栏、手动导出和结束后的自动导出均使用上下文整合文本，按场次和长段落排列，不重复附加逐句字幕。AI 校正开启时使用当前有效且已完成的校正文，其余段落使用原译文；关闭后全部使用原译文。导出仅包含已定稿的上下文，保留最后到达的已有译文；收起侧栏仍可导出。导出不会等待未完成的校正或发起新的 AI 请求。上下文组件暂不可用时，按已定稿原文和译文合并成长段落保存。

自动导出由“结束并导出”、时长上限或异常自动结束触发，手动暂停不会触发。最后一句收尾后异步写入本机 TXT（UTF-8 BOM），不等待写盘才允许下一次开始；暂停后点击结束也能导出已保留的字幕。每次结束使用独立文件，同次重复结束不会反复保存；没有新字幕的空连接不导出旧文本。自动保存失败或 8 秒内未确认时，会发起浏览器下载作为补救，请查看下载列表；也可手动点击“导出 TXT”。直接关闭浏览器、系统断电等不能保证完成结束导出，建议先点击“结束并导出”并查看页脚保存状态。

默认持续流式模式使用 `qwen-audio-3.0-asr-flash-streaming`：临时英文随识别结果持续更新，句子定稿后立即开始中文翻译，译文生成时逐步显示。此选择遵循当前课堂的速度优先需求；实际等待时间仍受停顿、音质和网络影响。

完整短句模式保留为可选项，使用 `qwen3-asr-flash-2026-02-10`：累计约5秒后遇停顿提交，连续讲话最长8秒一段，以保留更多句内语境；字幕等待还包括API处理时间。暂停时不足5秒的尾段也会提交。它是偏重句内语境的试用选项，尚未证明具有全课程最高准确率。

也可切换 Qwen Realtime 持续流式接口。Qwen Audio 3流式版接收即时金融热词；Qwen Realtime不支持本平台词库的识别热词输入。

暂停会立即停止采集，最多等待10秒收尾已接收的音频和译文，然后关闭本次实时连接，保留继续或结束的选择。断连、错误及超过时长上限会清理实时连接并自动结束导出。字幕和课堂设置发生变化后，每约5秒保存至本机私有草稿，手动暂停不影响草稿保存；重新载入页面后恢复为暂停状态，开始后才采集声音。草稿上限2 MiB，多页面冲突时提示导出，不覆盖另一页面的更新。关闭前仍可导出TXT备份；旧的同音频对比历史仍在对比页面回看。

## 为金融硕士课程准备

内置 **8 类课程、145 个精选英中术语、10 条翻译规则**：通用金融、公司金融、资产定价、固定收益、衍生品、投资组合、计量经济学、国际金融与外汇。外汇课程新增18个术语，区分银行与客户的买卖视角、直接与间接标价，以及货币升贬值的方向；原有债务口径与比率分母等歧义说明继续保留。

选课程后自动合并通用词表与该课程词表；自己的术语、人名和课程背景仍保留。规则强调数字、公式、单位、否定和假设条件；例如 `duration` 在债券语境为久期，`100 bps` 为1个百分点，`exercise` 在期权语境为行权、课堂语境仍可为练习。

词库是参考提示，不是对英文的机械替换，也不能恢复没有录清的声音。Qwen Flash/Plus和DeepSeek会得到完整领域规则，且明确保留can/may/might等限定词。专用Qwen MT Lite使用服务商的术语与领域参数，不接收完整Chat规则。识别侧按接口能力应用：Qwen3-ASR Chat 可用背景，Qwen Audio 3 ASR及持续流式版可用即时热词；旧 Qwen Realtime 不发送未文档化的热词字段。腾讯原生内置翻译不接收本平台的领域规则。

完整内容与官方参考来源见 `finance-pack.json`。这是一份面向课程整理的词库，不是某机构官方词表的完整复制。

## 同音频对比页面的使用方式

1. 在 **API 配置** 填写阿里云百炼北京地域与 DeepSeek 的 Key。本机只返回“已配置”状态，不把 Key 发回网页或写进项目。
2. 同一段真实课程音频先比较英语识别结果，再比较译文。一次最多3个方案，单段最多60秒。
3. 默认方案：腾讯 Lite 内置翻译、Qwen 热词识别→Qwen Plus、同一次 Qwen 热词识别→DeepSeek。后两条会复用同一个英文识别结果，只识别一次；实时榜型号可在识别下拉框切换。
4. 填写人工校对的英文参考稿后计算词错误率（WER）；越低越接近参考。没有参考稿不打分，WER也不能衡量中文翻译质量。
5. 选好组合后，回到实时翻译首页上课；当前推荐按速度优先选择持续流式识别。对比页的 **分段字幕** 仍可用于比较，按6/10/15秒分段后调用，完成整段才显示；等待时间包含分段时间和API处理时间。即使选用实时模型，此对比页面也采用分段比较。

停止会立即结束采集并取消进行中的分析。未完成尾段留在本机，可再主动比较。队列超过3段会停止以免越积越慢。首次按按钮才会采集或向所选平台发送数据；页面打开、录音试听和历史回看不调用云API。

### 真实课堂识别对照

用户反馈识别不够准确后，录制同一段37秒麦克风课堂声音，并行比较Audio 3持续流式、Qwen3-ASR HTTP新快照和Qwen3-ASR Realtime新快照，三组均仅转录。新实时快照多次输出“R B chart”，另外两组输出“arbitrage”。HTTP新快照收到整段音频后的处理耗时为1.47秒；两种流式包装会按真实音频时长重放，约40秒的总耗时不能与HTTP处理耗时当成模型延迟排名。

结果已存入本机历史 `2e1325f9-1248-4163-9a34-f389c972ccc3`。没有人工参考稿，因此不生成WER，也不能据此给出全课程准确率百分比。完整短句新快照曾用于课堂试用；现按用户明确的速度优先需求，将默认组合切回 Audio 3持续流式识别与 Qwen Flash 翻译，完整短句继续可选。国际金融与外汇词库及已有字幕保留；词库不会自动把“foreign cars”等疑似误词改写成猜测答案。

首次使用时需自行配置 Qwen 或 DeepSeek 密钥。百炼密钥若使用业务空间专属地址，请以控制台显示的服务地址为准；上表公共地址仅适用于支持它的密钥。

### 本次延迟修复与实测

修复了音频发送每100毫秒重复计时累加迟到的问题，改为按累计音频时长安排发送。离线模拟复现了旧版约38秒后积压超过3秒的情况；修复版在相同迟到条件下持续45分钟，队列保持在300毫秒以内。真实网络阻塞仍会触发保护。

同一10.15秒合成英语录音，Audio 3流式识别首段英文在连接开始后0.75–0.84秒出现；修复发送节奏后的旧Realtime为0.73秒。这些小样本不能证明新模型首字更快，也不能保证真实课堂具有相同延迟。当前默认采用 Audio 3流式方案以满足速度优先需求；上述数字是合成音接入记录。

Qwen Flash的两段流式文本测试首字为0.23–0.36秒，但后续也出现4.69秒等待，云端延迟有波动。新识别→Flash完整链路首句定稿后0.41秒出现中文。补强金融限定词后，另一次三句测试首字0.41秒、完成1.11秒，保留了“可能”“不一定”和条件句。Qwen MT Lite已加入选项，但测试中出现将可能结果译为确定结果的情况，因此暂不设为默认。上述原始运行记录只保留在原电脑，不随源码上传。

已用本地合成的14.885秒金融英语完成真实接口检查：Qwen热词识别与两种翻译均成功，整段识别加翻译约3.1–3.4秒；Qwen3-ASR快照识别约0.9秒；Qwen实时识别及后续DeepSeek翻译也成功。热词方案保留了“50个基点、5年久期、2.5%”。这些是接入验证，不是实际课堂准确率排名。原始WER会把`fifty`和`50`等格式差异计入错误。

实时接口已兼容maas网关定稿事件缺少`item_id`的实际返回，仅在能够确定唯一对应关系时接受。

- Qwen 开通与 Key：[阿里云官方说明](https://help.aliyun.com/zh/model-studio/get-api-key)
- DeepSeek Key：[开放平台](https://platform.deepseek.com/api_keys)
- 支持添加通用 `/audio/transcriptions` 语音接口及 `/chat/completions` 翻译接口。服务必须实现对应协议；没有宣称所有供应商都完全兼容。

配置保存在 `~/.config/classroom-api-lab/profiles.json`（Windows 为 `%USERPROFILE%\.config\classroom-api-lab\profiles.json`），限制当前用户访问；腾讯兼容入口使用原工具的专用子用户密钥。改变API目标主机时不会自动携带旧Key。

## 公开榜单：用于筛选，不能代替课堂测试

2026-09-15 查询 [Artificial Analysis 实时英语识别榜](https://artificialanalysis.ai/speech-to-text/streaming)，按最终转录 WER 从低到高：

| 名次 | 模型 | WER |
|---|---|---:|
| 1 | Meta Muse Voice Transcribe | 3.06% |
| 2 | Cartesia Ink-2（semantic endpoints） | 3.36% |
| 3 | ElevenLabs Scribe v2 Realtime | 3.59% |
| 4 | Alibaba Qwen3 ASR Flash Realtime | 3.73% |
| 5 | OpenAI GPT Live Transcribe | 3.92% |

这不是翻译榜或金融课堂专项榜。方法包含 AA-AgentTalk、VoxPopuli、Earnings22，财报会议语音占权重25%；详见[测试方法](https://artificialanalysis.ai/methodology/speech-to-text)。腾讯未在此榜找到可比条目，不能据此给腾讯排最后；其他榜的数据集和处理方式也不同。

本机WER仅做大小写、标点与词序对齐，不包含AA完整的数字/缩写归一化，不能把本机小样本分数与上述榜单数值直接比较。建议先在大陆可接入的Qwen与已有腾讯之间做同音频对照；海外服务可用性应另行核实。

## 数据、费用与验证状态

- 原始音频不写入后端磁盘。前端本地录音或上传音频仅在点击分析后发给已选择的语音提供商；文字转录和领域参考发给已选翻译提供商。
- 分析结果、参考稿和课程设置默认写到本机 `~/.config/classroom-api-lab/history/`，用于历史回看；也可导出TXT/JSON。不要把该私有目录上传到公开仓库。
- 每个独立API调用按对应平台计费。相同语音配置在同次比较中复用；选择多个不同语音模型会增加费用。停止后已经处理的部分仍可能计费，实际以平台账单为准。
- “历史测试示例”仅在保留了旧版测试文件的电脑上可用。离线测试使用模拟接口；本文合成音接入记录来自原电脑的真实 API 测试，不包含在全新安装的历史记录中。
- 离线测试覆盖持续流分句、原生WSS热词识别、中文SSE输出、长课堂音频节奏、maas事件兼容、切换所选API、停止/断连清理、背压与队列、时长上限、密钥隔离、同音频复用、访问来源检查及WER。

开发运行：Node.js 24，`node server.mjs`。唯一额外依赖为 `ws`，版本锁在 `pnpm-lock.yaml`。离线验证：`node --test`。

`verify-live-connection.mjs --call-api` 是手动真实接口检查，会调用已配置的语音和翻译API；不会随离线测试自动运行。
